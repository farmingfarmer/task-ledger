# task-ledger

## Mnemo bridge log (read at session start)

Recent activity from Mnemo (the desk/voice assistant) is appended
to `.mnemo/bridge_log.md` -- the questions asked of Mnemo about this
project, its answers, and any walkthroughs. At session start, and
whenever work references something done "on the other screen" or
"asked Mnemo," read that file so this terminal shares context with
Mnemo instead of being blind to it. The file is local only
(git-excluded) and never travels.
