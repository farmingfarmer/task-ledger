Revision: 2026-10-05b · mission: ingest the expanded Copilot export + all new sources, run the pipeline, reship the kits

Right now: copilot_claims_raw.txt has grown new meeting summaries. Feed everything new into both ledgers — transcripts first (anchoring matches Copilot’s quotes against transcripts already on disk, so order matters), then the Copilot export, then any status reports — run the tick, review your own cards, and rebuild the kits so the team finally sees September and October.

1 · Update the machine

cd %USERPROFILE%\dev\task-ledger
git pull

2 · Transcripts first (only if transcripts_raw.txt has new meetings)

This must run BEFORE the Copilot import: quotes in the export can only earn receipts against transcripts the system already holds.

tl.bat transcripts transcripts_raw.txt

3 · The expanded Copilot export

Dry run first, and read one line of its output: “N of M claim(s) matched a sentence in your transcripts”. That anchor rate is the round-2 number for the decision memo — write it down.

python scripts\copilot_claims_ingest.py copilot_claims_raw.txt --dry-run

Then rebuild the comparison ledger from scratch (it exists only for this; rebuilds are free):

tl.bat copilot copilot_claims_raw.txt --apply

4 · Status reports (repeat per person, as they arrive)

Jason’s format, as written: “Week of MM/DD:” headings with bulleted tasks. Each line becomes a claim authored by that person about their own work, with the report line as its receipt — and it still arrives as a review card, never a board row.

tl.bat statusreport jason-status.txt --for jason-tjia

5 · Run the pipeline

tl.bat ollama
tl.bat tick

The tick announces which models it picked and reconciles everyone with claims waiting. If it bows out on the lock and you are sure nothing real is running: tl.bat tick --steal.

6 · Review your own cards

tl.bat dashboard --hands-on --picker

Answer your review popup. Things worth eyeballing while you are in there: estimate phrases on cards (“Estimate: 2 points” driving the week sheet), “Files under…” parent hints, and a receipt page on any accepted task naming its meeting in words. Ctrl-C the dashboard when done — the kit build needs port 8090 free later.

7 · The two session lines (fresh window only)

tl.bat blind alexander-marunycz yesha-patel jason-tjia lorenzo-rossi patrick-toral --balance

Paste the set "TL_BLIND_SALT=..." line it prints, then:

set "CPDSN=host=localhost port=5433 dbname=taskintel_copilot user=%USERNAME%"
