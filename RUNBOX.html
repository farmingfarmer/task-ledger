Revision: 2026-10-19 · mission: kits for the whole ledger — one command builds and zips a kit per person; return address is the med.usc.edu one.

Right now: Jason’s verdict landed and we agree: one mechanism, the Copilot-summaries ledger. The cycle below is SHORTER than the old one — no tick, no blind, no second arm. tl kit now ships the copilot ledger by default, and status reports reconcile themselves on ingest. Transcripts still go in first: they are what turns Copilot’s quotes into receipts.

1 · Update the machine

cd %USERPROFILE%\dev\task-ledger
git pull

2 · Transcripts first (whenever transcripts_raw.txt has new meetings)

The local extractor is retired, but transcripts are promoted, not dropped: every Copilot quote that matches a sentence on disk earns a checkable receipt, the real speaker, and the confidence to propose completions. No transcripts, no receipts.

tl.bat transcripts transcripts_raw.txt

3 · Rebuild THE ledger from the Copilot export

Model server first (the build refuses to drop anything without it), then a dry run — write down the anchor-rate line (“N of M claim(s) matched a sentence”), it goes in the decision memo — then the rebuild. This database is now the product, not the comparison arm; rebuilds are free and total.

tl.bat ollama
python scripts\copilot_claims_ingest.py copilot_claims_raw.txt --dry-run
tl.bat copilot copilot_claims_raw.txt --apply

4 · Status reports — EVERY cycle, right after the rebuild

The rebuild starts from scratch, so reports re-apply each time (deterministic ids: nothing duplicates). New: --dbname lands them in the shipping ledger and reconciles the person on the spot — report in, review cards out, no tick. Report content never enters the repo, same fence as transcripts.

tl.bat statusreport jason-status.txt --for jason-tjia --dbname taskintel_copilot

Repeat per person as reports arrive. When Jason’s FULL report lands, overwrite jason-status.txt and run the same line.

5 · Review the ledger that ships

New flag: the dashboard serves the copilot ledger directly — no environment editing. The banner confirms with “ledger: copilot extraction”. Check Jason’s missing list while here: sharepoint revamping, one-pagers, the Abbott deck (that one arrives only via his status report). Ctrl-C when done — the kit build needs port 8090 free.

tl.bat dashboard --ledger copilot --hands-on --picker

6 · Build a kit for EVERYONE (one command)

Enumerates every real person the shipping ledger knows, builds each kit, and packs each into a send-ready zip. Run it once WITHOUT --apply first and read the list of names it prints — the ledger is identical in every kit, so each zip goes only to someone who was in the corpus meetings. The return address on every kit is the work one.

tl.bat kit --for-everyone --return-to "Alex Marunycz (alexander.marunycz@med.usc.edu)" --with-runtime --with-postgres --zip
tl.bat kit --for-everyone --return-to "Alex Marunycz (alexander.marunycz@med.usc.edu)" --with-runtime --with-postgres --zip --apply

No Task Ledger black window open anywhere. Zip your own kit, extract somewhere fresh, double-click START-TASK-LEDGER.bat — it must boot straight into the single ledger, no A/B picker. Walk to the greeting, type one capture note, watch it become a card, open one receipt.
