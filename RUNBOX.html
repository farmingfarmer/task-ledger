Cold start (any morning, after any reboot)

Three actions, no set lines, no memory required.

1. Windows key → type Ollama → Enter (tray icon = server running).
tl.bat tick
tl.bat dashboard --hands-on --picker

Rescues

Another tick holds the lock and you are sure it should not (or are happy to let this run redo its window):

tl.bat tick --steal

Ollama not answering and the Start-menu route did not take:

start "ollama" "%LOCALAPPDATA%\Programs\Ollama\ollama.exe" serve

Anything else: photograph the black window — every failure now prints its own explanation, and the photo is the complete bug report.
